# Data, model assets, and access boundary

The exact revised-split study used 1,100 D-Fire images (864 fire-positive and 236 no-fire), 427 retained visual-association components, five frozen TEST folds, and three classifier seeds. Source images and labels can be obtained only under the original providers' applicable terms. This archive contains no pixels, labels, exact study selection/fold map, component membership table, CAL threshold seal, image-level prediction table, trained model, or run receipt.

The initial classification weights were recorded as `yolo26s-cls.pt`; any other initial assets required by a selected execution path must be obtained lawfully and checked against the frozen run manifest. The package does not download weights automatically and does not assert that a later download matches the historical bytes.

To recompute the manuscript's reported numbers, an authorized operator needs the exact frozen image-level predictions for each method/seed/view, labels, fold and component assignments, the CAL-selected thresholds, and the recorded analysis configuration. To retrain, the operator additionally needs the exact selected images and labels, pretrained assets, execution environment, and training resources. Those items have not been approved for external distribution or reviewer access by this source release.

The original D-Fire repository describes third-party source images and asks users to check the original providers' terms. This source-only package does not grant image reuse or redistribution rights.
